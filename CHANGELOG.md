# Changelog

## 0.3.0 — 2026-10-27

- Selectable automatic repair categories and individual boundary/island/cavity findings.
- Transactional repair preview, after-checks, commit/cancel and persistent JSON reports.
- Duplicate/loose/degenerate cleanup, nested-shell normal orientation and bounded hole filling.
- Voxel repair of detected intersections/nonmanifold topology and sampled wall correction.
- Automatic downward drains, selected cavity filling and island support/removal.
- Source/configuration validation, resource limits and restore behavior after file reload.
- More robust sub-voxel retries for tangent diagnostic rays.

## 0.2.0 — 2026-10-27

- Causal floating-island grouping, spatial issue navigation and overlays.
- 3D voxel reconstruction, clipping, layer comparison and buildup playback.
- Center of mass, contact footprint and local analysis archives.
- UVtools grouped-island capability detection and end-check.

## 0.1.0 — 2026-10-27

- Initial mesh checks, hollow copies, cursor-positioned drain holes, straight supports and millimeter STL export.

All versions are development versions; real print validation remains outstanding.
